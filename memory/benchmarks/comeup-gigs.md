## 2. Anatomie commune

- Titre : "Je vais [verbe] votre [objet] avec [outils]" + mots-clés outils (n8n, Make, Zapier, IA). Préfixe imposé par ComeUp. Titres génériques = SEO interne.
- Structure de prix : Basique 16-55 € sans option (appât) puis "Personnalisé" jusqu'à 6-21 options à tiroirs (étape IA +50 €, multi-étapes +77 €, maintenance 30 j +350-520 €, visio 30 min +33-77 €, webhook +11-22 €). Le vrai panier = options. Délai de base 1-7 j.
- Couverture/galerie : vignette type YouTube avec le titre en surimpression + 5-10 images (captures de scénarios Make/n8n, logos d'outils, témoignage). Vidéo présente chez le n°1 (déduit, NON VÉRIFIÉ).
- Description (600 à 4 000 mots) : accroche douleur -> liste de livrables -> cas d'usage -> processus 5 étapes -> prérequis/ce qui n'est pas inclus (abonnements, crédits IA) -> FAQ -> appel à contacter avant commande. Le n°1 ajoute 4 réalisations chiffrées, "pour qui / pas pour qui", comparatif Zapier/Make/n8n : ton direct, sans jargon, limites annoncées. Les n°2 et 6 sont très longs, promotionnels, avec fautes et chiffres non sourcés.
- Preuves : badge Top service + Performance Top ; réponses du vendeur aux avis ; clients récurrents.
- Avis : réactivité, rigueur, "tout fonctionne", communication fluide, délais respectés. Quasi aucun avis ne cite un résultat métier chiffré.

## 3. Failles exploitables

1. Aucun vertical : tous "automatisation IA" générique. Rien vu sur logistique/transport/e-commerce physique (suivi colis, retards, bons de livraison) dans les 48 fiches. Seules niches : réseaux sociaux, prospection B2B, WordPress-HubSpot, Telegram.
2. Livrables flous ("1 scénario, 3 tâches") sans exemple de résultat concret ni démo vidéo de workflow qui tourne.
3. Incohérences prix description/checkout et options grisées (limite 151 j/5 000 €) chez presque tous : crédibilité faible.
4. Peu de garanties : aucune fiche vue ne promet remboursement ni documentation + test + 7 j de correction de façon claire (seul Flowriel_ai cite 1 correction + doc).
5. Peu d'exigence sur la propriété : n8n self-host/clé API au nom du client évoquée seulement par Thomas_Automation.
6. Extraction de documents par IA (factures, BL, CMR vers tableur/base) : non vu dans les 48 fiches (recherche limitée à une page ; à vérifier avec une recherche dédiée).
7. Nouveau vendeur = 0 avis : la barrière est la preuve sociale. Les débutants (Flowriel_ai, skoro) partent à 16-33 €. Il faudra un prix d'appel assumé pour les 3-5 premiers avis.

## 4. Trois services proposés (prix affichés acheteur, ~ vendeur x 1,102 ; NON VÉRIFIÉ : commission et net, à contrôler à la création)

**S1. "Je vais automatiser vos flux logistiques et e-commerce avec n8n et l'IA"** (alertes retards transporteur, suivi colis vers client, relances, rapprochement commandes/stock vers tableur ou Supabase)
- Essentiel 49 € / 3 j : 1 workflow (1 déclencheur, 2 outils, 5 nœuds max), test sur vos données, doc 1 page, 1 correction.
- Standard 149 € / 7 j : 2 workflows, notifications mail/Slack/Telegram, journal des erreurs, 1 étape IA (classement/résumé), enregistrement vidéo de démonstration.
- Premium 349 € / 14 j : jusqu'à 4 workflows liés, base Supabase, tableau de suivi, installation n8n (cloud ou VPS conseillé), 7 j de support.
- Hors prix : abonnements n8n/hébergement, crédits API, annoncés d'emblée. Pas de promesse de gain chiffré.

**S2. "Je vais créer votre assistant IA qui répond à vos clients à partir de vos documents"** (site web ou email ; Claude API + base de connaissances Supabase)
- Essentiel 99 € / 5 j : 1 assistant web (widget), jusqu'à 20 documents/FAQ, règles de ton, test avec 20 questions.
- Standard 249 € / 10 j : + transfert à un humain par email, historique des conversations, limites de coût API réglées, doc d'exploitation.
- Premium 549 € / 18 j : + 1 intégration (agenda ou CRM), tableau de suivi des questions sans réponse, 14 j de réglages.
- WhatsApp : seulement en option après vérification des contraintes Meta (compte Business, coûts) ; ne pas la promettre en base.
- Honnêteté : l'assistant peut se tromper ; garde-fous et "je ne sais pas" paramétrés, pas de service client 100 % autonome.

**S3. "Je vais extraire les données de vos factures, bons de livraison et PDF avec l'IA"** (PDF/photos vers Google Sheets, Excel ou base ; n8n + Claude)
- Essentiel 59 € / 3 j : 1 type de document, 1 destination, test sur 20 de vos documents, taux de lecture correcte mesuré et communiqué.
- Standard 169 € / 7 j : 3 types de documents, contrôle de cohérence (totaux, doublons), alerte sur les cas douteux, doc.
- Premium 429 € / 14 j : flux complet (boîte mail ou dossier -> extraction -> base Supabase -> export), validation humaine intégrée, 14 j de support.
- Hors prix : coût API par document (estimé et donné avant commande). Pas de "100 % de précision".

Recommandation de lancement : S1 (vertical, débutants rassurés, ma légitimité logistique) en n°1, S3 en n°2 (niche, peu de concurrence vue), S2 en n°3 (panier fort mais fiches concurrentes plus nombreuses).

## 5. Grille de notation d'une fiche (critique : 1-5 par critère ; cible >= 4 partout)

Un critère à 5 = description ci-dessous entièrement remplie.

1. Clarté de l'offre : titre "Je vais..." avec résultat + outil + cible ; un inconnu comprend en 5 s ce qu'il reçoit. 5 = vertical nommé, aucun jargon, 0 mot vague.
2. Livrables vérifiables : chaque palier liste nombre de workflows/outils/documents, ce qui est testé, doc fournie, ce qui est exclu. 5 = tableau 3 paliers sans zone floue, prix et délais identiques description/options.
3. Preuve et démo : vidéo ou captures réelles d'un workflow qui tourne, exemple avant/après ; aucun faux avis/chiffre inventé. 5 = vidéo 60-90 s + 3 captures annotées + exemple chiffré honnête (marqué "exemple").
4. Structure et lisibilité : hook problème -> livrables -> processus -> prérequis -> FAQ -> appel au contact ; 700-1 200 mots, titres, listes. 5 = scannable en 1 min, FAQ >= 6 questions réelles, pas de pavé.
5. Honnêteté et garde-fous : coûts tiers, limites, risques d'erreur IA, propriété des accès exposés ; aucune promesse de revenu. 5 = section "Ce qui n'est pas inclus" + garanties réelles (1 correction, doc, support) tenables.
6. Prix et paliers : entrée accessible pour obtenir les premiers avis, options cohérentes, panier moyen par options pertinentes. 5 = Essentiel <= médiane marché (33-55 €), upsell logique, cohérent avec le temps réel de Baptiste.
7. Visuels : couverture lisible en vignette (titre court, outil visible, style cohérent entre les 3 fiches), galerie sans captures de données de tiers. 5 = comparable aux n°1-3, texte lisible à 200 px.
8. Référencement et conversion : mots-clés recherchés (n8n, automatisation, IA, vertical) dans titre/début de description/tags, catégorie correcte, appel à écrire avant commande. 5 = présent dans les 3 zones sans bourrage.

Procédure : critique (autre agent, sans voir le raisonnement) note la fiche vs ce fichier ; 2 passes de correction minimum.
